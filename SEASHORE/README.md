# Redowan's Seashore Finds — Generative Percussion

A browser-based generative percussion instrument built from 54 field-recorded sounds made with objects found on the seashore. Built with React, Vite and the Web Audio API.

## Features
- 16-voice, 16-step editable sequencer
- Generative patterns for House, UK Garage, Jungle, Breakbeat, Downtempo and Experimental
- Randomise patterns and per-voice sample selections
- 16 playable voice pads with sample auditioning
- Tempo and swing controls
- Bundled looping shoreline field recording
- Independent sea ambience level, granular cloud and shimmer controls
- Low-pass filter, saturation, reverb, delay and master compression
- Custom coastal palette and responsive interface

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel
- Framework: Vite
- Root directory: `SEASHORE`
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

The sea ambience is bundled with the project. There is no ambience upload control.
