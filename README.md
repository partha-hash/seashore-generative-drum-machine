Seashore — Generative Drum Machine

Seashore is an experimental generative drum machine built around sounds recorded from objects found along the seashore. It uses these recordings as percussion sources to create unusual rhythms and textures, with a focus on house, techno and experimental electronic music.

About the Project

My family and I have always been fond of the beaches of Bangladesh. Over the years, we collected different objects and souvenirs from our trips to the coast.

I eventually became interested in the sounds these objects could produce. I started recording their individual timbres and turning them into a sample library, exploring how ordinary materials could be used as musical instruments.

Seashore grew out of that experiment. It's a way of appreciating these objects and the memories attached to them through sound.

Features

- Generative drum patterns: Randomized rhythmic patterns inspired by house and techno.
- Shuffle Sounds: Explore different combinations of percussion samples.
- Found-sound sample library: Recordings made from physical objects collected along the coast.
- Sound manipulation: Shape the samples using built-in audio effects and DSP controls.
- Pitch control: Adjust the pitch of individual sounds.
- Experimental rhythm generation: Discover unexpected rhythmic combinations without manually programming every hit.
- Mobile-friendly interface: Designed to work on mobile devices with lightweight visuals and controls.

Sound Sources

The sample library explores the acoustic characteristics of different materials, including:

- Stones and pebbles
- Seashells
- Driftwood
- Broken glass
- Styrofoam fragments
- Other objects found along the shoreline

Each material has its own sonic character, from sharp clicks and hollow resonances to dry impacts and textured noise.

Musical Direction

Seashore is mainly intended for experimenting with:

- House
- Deep house
- Minimal techno
- Experimental electronic music
- Ambient percussion
- Organic rhythmic textures

It can be used as a rhythm generator, a source of unusual percussion sounds, or an experimental instrument for electronic music production.

Technology

The project uses web technologies and browser-based audio processing to generate and manipulate sounds in real time.

The interface and audio engine are designed to work together, keeping the experience accessible without requiring a traditional desktop music production setup.

Getting Started

Clone the repository:

git clone https://github.com/partha-hash/seashore-generative-drum-machine.git

Navigate to the project directory:

cd seashore-generative-drum-machine

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL provided by the development server.

These commands assume the project uses a standard npm-based setup.

Project Status

Seashore is an ongoing personal experiment. The sample library, sound processing and interface are still evolving.
